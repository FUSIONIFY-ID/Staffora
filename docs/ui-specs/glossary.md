# Glosarium UI Staffora

Glosarium ini mencatat istilah yang muncul di teks UI `apps/web/src`, supaya FE tidak menerjemahkan istilah sendiri. Setiap usulan ditandai "belum dikonfirmasi PRD", karena PRD tidak ada di repo.

- Snapshot: commit `2647e0a` pada branch `QA-S1-DOC-docs-restructure`, dibaca 2026-11-02.
- Pencarian: `apps/web/src/app`, `apps/web/src/components`, `apps/web/src/features`, dan `apps/web/src/App.tsx`. Folder `apps/web/src/api` dibaca hanya untuk pesan fallback.
- Lokasi berformat `file:baris`, dengan path relatif terhadap `apps/web/src/`.
- Singkatan dokumen: `design-system.md` = `docs/ui-specs/design-system/design-system.md`; `round-N.md` = `docs/ui-specs/app-shell/qa/round-N/round-N.md`; `rbac-matrix.md` = `docs/security/rbac-matrix.md`.
- Status **Konsisten**: istilah hanya muncul dalam satu bentuk. Status **Tidak konsisten**: istilah yang sama muncul dalam dua bentuk atau lebih, dan usulan memilih satu bentuk.

## Aturan

1. Identifier kode memakai English: nama variabel dan konstanta (`ROLE_LABELS`), route (`/my-profile`), enum (`PROJECT_MANAGER`), field API, dan nama tabel. Identifier tidak tampil ke pengguna.
2. Teks UI yang dibaca pengguna memakai Bahasa Indonesia. `CLAUDE.md` mengizinkan English bila PRD menetapkannya, dan PRD adalah acuan akhir.
3. Urutan acuan: PRD, lalu desain (Figma lewat `docs/ui-specs/`), lalu kode. Jika kode berbeda dari desain, catat sebagai Tidak konsisten. Jangan menebak.
4. Figma masih memakai English untuk beberapa label (`design-system.md` baris 100 dan 102, `round-1.md` baris 36). Usulan Bahasa di bawah bisa berbeda dari desain, jadi keputusan bahasa perlu ditetapkan PRD atau Tech Lead lebih dulu.
5. Nama peran selalu lewat `ROLE_LABELS` di `app/roles.ts`. Komponen tidak membuat label peran sendiri.
6. Istilah baru ditambahkan ke file ini sebelum dipakai di kode.
7. Merek `Staffora` dan slogannya tidak diterjemahkan.
8. Pesan error ke pengguna berupa kalimat lengkap yang diakhiri titik, sesuai pola di `features/auth/login-error.ts`.
